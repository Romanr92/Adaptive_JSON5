## Owner decisions (2026-11-25)
- D1 Layout: everything under `cli/` (private headers `cli/includes/cli/`, sources
  `cli/src/`, `main.cpp`).
- D5 (owner, 2026-11-25): the CLI's GoogleTest units live in `cli/test/` (moved from
  core/tests/cli; own CMakeLists, built with ADAPTIVE_JSON5_BUILD_TESTS); AGENTS.md lists
  `cli/test/` as an allowed test location; registry/traceability paths updated.
  The pure-memory test keeps scanning only core/ and includes/; the complexity report
  also measures cli/.
- D2 Encoding: values strict JSON cannot carry losslessly are tagged objects:
  lone-surrogate strings `{"$utf16": [units...]}`, non-finite numbers
  `{"$number": "Infinity"}`; all other strings escaped JSON.
- D3 Manifest observations become structured, machine-checked assertions (prose kept as
  description); manifest format_version 2.
- D4 Memory: host-only tool, heap allowed (malloc-backed storage callbacks, generous
  budgets); no std allocating containers in tool logic so allocation failure is reported
  (preformatted minimal diagnostic, exit 2) and unit-testable.

## Shape
- One host executable `adaptive_json5_examples` with commands `validate`, `inspect`,
  `run` (+ `--version`, `--capabilities`), behind `ADAPTIVE_JSON5_BUILD_EXECUTABLE`.
- Injectable seams: `input_reader` (file/stdin), `output_sink` (stdout/stderr),
  `storage_callbacks`; `main.cpp` wires the real cstdio adapters.
- Exit: validate/inspect 0 valid, 1 input/assertion/profile invalid, 2 configuration/I/O/
  operational; run 0 all selected supported expectations matched, 1 mismatch,
  2 operational; unsupported capabilities never count as passing.
