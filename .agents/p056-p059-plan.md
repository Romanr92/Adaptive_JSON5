## Shape
- One host executable `adaptive_json5_examples` with commands `validate`, `inspect`,
  `run` (+ `--version`, `--capabilities`), behind `ADAPTIVE_JSON5_BUILD_EXECUTABLE`.
- Injectable seams: `input_reader` (file/stdin), `output_sink` (stdout/stderr),
  `storage_callbacks`; `main.cpp` wires the real cstdio adapters.
- Exit: validate/inspect 0 valid, 1 input/assertion/profile invalid, 2 configuration/I/O/
  operational; run 0 all selected supported expectations matched, 1 mismatch,
  2 operational; unsupported capabilities never count as passing.
